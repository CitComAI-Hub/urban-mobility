# Road network of Valencia

`valencia.net.xml.gz`: SUMO network built with `tools/build_network.sh` (netconvert
1.25.0) from OpenStreetMap data of 2026-05-31 (roads for motor vehicles in the area
of the Ajuntament's traffic measurement points).

Map data © OpenStreetMap contributors, available under the
[Open Database License (ODbL)](https://opendatacommons.org/licenses/odbl/1-0/).
This network is a derived database and is shared under the same licence.

It has not been calibrated yet (lanes, traffic lights, entries at the edges of the
area): see "Accuracy" in the README.
